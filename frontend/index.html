Held-Out Test Set Performance & Imbalance Engineering

Prior to splitting, all 10,025 files were hashed with MD5, purging 121 exact byte-for-byte duplicates so zero identical images leaked between train (7,924), validation (990), and test (990). The 6.5:1 class imbalance between momo (2,219) and chatpate (342) was solved via smoothed inverse square-root sampling ($\sqrt{\bar{N}/N_c}$) and label smoothing ($\epsilon = 0.1$, mathematical loss floor $0.5004$).
