How the 3 Architectures Performed

Trained with two-stage transfer learning on an NVIDIA RTX 4050 GPU. To handle the 6.5:1 imbalance between momo (2,219 photos) and chatpate (342 photos), we used smoothed square-root sampling (wc = √(N̄ / Nc)) and label smoothing (ε = 0.1, theoretical loss floor 0.5004).
